# FitOS 视觉设计系统 V2

FitOS 训练界面采用浅色健康管理风格。唯一的颜色、圆角、间距和阴影定义在 `src/fitos/theme.ts`；Web 预览样式与原生 FitOS 训练页复用这些 Tokens。训练计划、日志模型和存储适配层不因视觉升级而改变。

## 核心颜色

| 用途 | Token | 色值 |
| --- | --- | --- |
| 页面背景 | `background` | `#F5FAF8` |
| 品牌主色 / 主要操作 | `primary` | `#008F7A` |
| 强调背景 / 选中状态 | `primarySoft` | `#DDF4EC` |
| 主标题 | `heading` | `#183B35` |
| 卡片 | `card` | `#FFFFFF` |
| 辅助文字 | `muted` | `#6F8A83` |

卡片使用轻阴影和柔和边框；主要按钮为青绿底白字，次级按钮为白底青绿字。未记录的体重显示“暂无记录”，不使用示例数字伪装成用户数据。

## 页面与导航

- 概览：首页只有一个突出的“开始训练”按钮；进度卡展示本周完成次数、所选周数和建议下一课。计划阶段与最近体重独立成卡片，训练安排用列表呈现。
- 计划：12 周选择、三天/四天节奏、动作处方和进阶说明。
- 训练：逐组重量和次数输入、完成状态、训练日期及 60/90/120/180 秒休息计时。
- 历史：训练日志与体重趋势；无数据时使用清楚的空状态。

浏览器宽度小于 700px 时使用固定底部导航；较宽时使用顶部导航。主要内容最大宽度为 860px，移动端保留足够的触控空间。按钮提供按压反馈，选中项提供视觉与可访问性状态。

Web 预览的日志仍保存在当前浏览器 `localStorage`，原生训练日志仍使用 SQLite。两者不自动同步；Web 页面不访问 HealthKit 或 Apple Watch。
